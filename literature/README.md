# Literature

This folder tracks reading for the programme. The [reading list](reading_list.md) currently contains only the references already cited in the [research charter](../docs/research_framework.md).

Copying a citation into that list is not a review. Each entry states how far this repository has gone with the source. Initialization did not include a literature search and does not claim that the programme is novel. The charter says novelty is assessed per subproject.

Add a source when a study uses it. Record who read it and what they took from it. A pointer from the charter remains marked as unread until someone records a review.

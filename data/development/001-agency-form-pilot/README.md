# Development material for 001

These files are development examples for [the proposed protocol](../../../experiments/001-agency-form-pilot/protocol.md). They were drafted on 9 October 2026 for owner review.

They are not a training corpus, not a held-out set, and not evidence about a model. No weights were trained on them. The situations they use are ineligible for later confirmation data, including paraphrases of the same situations.

Held-out text is not stored here. Putting a file in another directory would not make it held-out.

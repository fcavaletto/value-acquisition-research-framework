# Handoff

Replace these prompts at the end of a work session. Leave the next session able to continue without guessing.

## Task

State the bounded task.

## Relevant documents

List the charter sections, the protocol, and any decision-log entries that apply.

## Inputs

List data versions, checkpoints, and configurations the task may use. State whether confirmation data is in bounds. The default is that it is not.

## Allowed changes

State which files and scientific choices the task may change. Changing the charter, the primary question, or the claim the study can support requires the research owner.

## Completed work

State what was finished. Distinguish a document edit from a run.

## Commands actually run

List commands that were executed and what they were for. Omit commands that were only considered.

## Findings

State observations from the completed work. If nothing was run, say so. Do not treat agent agreement or unreviewed labels as evidence.

## Unresolved decisions

Point to items still awaiting the research owner.

## Next task

State the single next task and what it must not assume.
